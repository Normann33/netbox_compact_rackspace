# NetBox Compact RackSpace Plugin

Ультра-компактная матрица заполненности стоек (тепловая карта) для **NetBox v4.7.x**, вдохновленная модулем RackSpace из DCIM-системы **RackTables**.

Плагин решает проблему громоздкого стандартного отображения (Rack Elevations), выводя абсолютно все стойки на один экран в виде адаптивной пиксельной сетки. Данные обновляются мгновенно благодаря оптимизации SQL-запросов (`prefetch_related`), предотвращая проблему N+1.

## Основные возможности

* **Ультра-компактный вид:** Стойки масштабированы по горизонтали и вертикали, автоматически заполняют ширину экрана и переносятся без появления бокового скролла.
* **Пиксельное схематичное отображение:** Юниты отображаются тонкими полосками без лишнего текста. Темно-зеленый цвет — занято устройством, светло-зеленый — свободно.
* **Интерактивные подсказки:** Наведение курсора на юнит показывает номер юнита и имя устройства. Клик по ячейке открывает карточку сервера в новой вкладке.
* **Иерархическая группировка:** Стойки автоматически распределяются по Площадкам (Sites) и Локациям (Locations).
* **Связанные фильтры:** Динамическая фильтрация по площадкам и локациям вверху страницы.

## Установка в NetBox Docker

### 1. Добавление плагина в сборку
Откройте конфигурацию сборки плагина `Dockerfile-Plugins` на вашем сервере хоста и добавьте инструкции копирования и сборки:

```dockerfile
FROM netboxcommunity/netbox:v4.7.3

USER root

# Клонирование плагина напрямую в контекст сборки образа
RUN /usr/local/bin/uv pip install --no-cache git+https://github.com

USER 0
```

### 2. Активация плагина в NetBox
Откройте файл конфигурации плагинов NetBox `configuration/plugins.py` и добавьте имя плагина в список:

```python
PLUGINS = [
    'netbox_compact_rackspace',
]
```

### 3. Пересборка контейнеров
Примените изменения, принудительно очистив кэш образов и перезапустив проект:

```bash
sudo docker-compose down
sudo docker-compose build --no-cache netbox netbox-worker netbox-housekeeping
sudo docker-compose up -d
```

## Использование

После успешного запуска в левом боковом навигационном меню NetBox (в самом низу, в блоке установленных плагинов) появится новый пункт: **«Компактный RackSpace»**. 

При переходе по ссылке откроется интерактивный дашборд. Фильтры вверху страницы динамически связаны: при выборе конкретной Площадки список доступных Локаций автоматически сократится до объектов, относящихся исключительно к ней.
